# agentpulse-mcp

Standalone MCP (Model Context Protocol) server for [AgentPulse](https://github.com/jstuart0/agentpulse) — talk to any running AgentPulse instance from Claude Code, Codex CLI, or any other MCP-compatible client, without cloning the AgentPulse repo.

> Not yet published to npm. Until it is, run the MCP server from a checkout of the main repo (`agentpulse mcp serve`) — see `docs/MCP.md` there.

This README is filled in fully in the documentation phase of the extraction campaign (2026-07-23-deliver-agentpulse-mcp-package, phase 5).
