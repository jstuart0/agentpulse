Control your coding agent fleet from Claude Code over MCP

The dashboard is for you. The MCP server is for your agents. With @craze0/agentpulse-mcp, Claude Code, Codex CLI or any Model Context Protocol client can see what your other sessions are doing, and, if you allow it, launch and steer them.

What an agent can do with it

Some things you can ask a Claude Code session once the server is connected:

  • "Which of my sessions are waiting on me right now?"
  • "Search my sessions from last week for the migration we discussed."
  • "What did the session in the api repo change?"
  • "Start a Codex session in the docs repo to update the changelog." (needs a manage key)

Install

You need a running AgentPulse server. Then, with no checkout of the repository:

npx @craze0/agentpulse-mcp install --mint my-agent

This mints an API key and prints configuration ready to paste into Claude Code or Codex CLI. By default the key is observe-only: it can read sessions and search, and nothing else.

From a checkout of the repository, the same is available as agentpulse mcp install. Add --orchestrate to mint a manage key that can also launch and steer. Read the security notes below first.

The tools

TierExamples
Read (observe)list_sessions, get_session, get_session_timeline, search, get_stats, get_digest, list_projects_summary
Read (manage)list_templates, list_launches, get_inbox, list_hosts
Act (manage)launch_agent, prompt_session, stop_session, retry_launch, update_session, decide_hitl, decide_action_request

Some reads need manage because what they return can include environment variables or launch specs. The full catalog is in docs/MCP.md.

Security notes

  • The API key's scope is the real boundary. An observe key can't launch anything, whatever the client does.
  • Mutating tools are marked so Claude Code asks for confirmation. Codex CLI and headless MCP clients ignore that marker, so a manage key there acts without asking.
  • prompt_session, stop_session and retry_launch work only on sessions AgentPulse launched. Sessions you started in a terminal can be read, not steered.
  • Install from npm's listing for @craze0/agentpulse-mcp. Near-miss names are not this package.
